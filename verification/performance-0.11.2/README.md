# 0.11.2 主题性能扫描与优化

2026-11-15。基线 `aa44bbf` / 0.11.1；优化版 0.11.2。发现并修复了可重复出现的 CSS 样式匹配热点，同时减少偏好更新与设置导航的无效工作。

## 测量结果

真实 DSH 0.2.2-rc.3 隔离 profile，Codex 内置 Chrome 157，1280×720、2×。同样的自动化操作，使用 Chromium `Performance.getMetrics` 的累计值差分。各组排除首轮预热，使用剩余样本的中位数；设置与输入各 11 个样本，插件页设置开关各 7 个样本。

| 场景 | 0.11.1 样式计算 | 0.11.2 样式计算 | 降幅 | 全部主线程任务 CPU：前 → 后 |
| --- | ---: | ---: | ---: | ---: |
| 空会话页打开并关闭设置，一轮两次点击 | 154.248 ms | 47.872 ms | 69.0% | 188.250 → 89.595 ms |
| 输入框更新一次测试文本 | 21.907 ms | 5.007 ms | 77.1% | 27.472 → 10.107 ms |
| 插件页打开并关闭设置，一轮两次点击 | 151.288 ms | 47.970 ms | 68.3% | 187.007 → 97.204 ms |

这些是特定操作期间渲染线程的 CPU 用时，包含宿主和测量操作，不是点击到显示的端到端耗时、逐字符输入延迟、FPS 或整个应用的提速倍数。输入通过填入短测试草稿触发，随后已清空；没有调用模型。原始每轮记录、各分项数据见同目录 JSON 与 `summary.json`。

## 主要问题与修复

### 1. 大型图标规则对普通元素和隐藏图标定义重复匹配

旧规则把 102 个图标族和 64 处内联 SVG 合并为大型 `:is(...)`，再用 `> *` 隐藏原始图形。通配子节点让普通 HTML 元素及宿主隐藏图标仓库也进入这组昂贵匹配。

- 给共同规则增加 SVG 标签入口，使用 `:where(svg)` 保持原来的选择器权重。
- 子节点只匹配 SVG 绘图元素和所需容器，不再匹配所有 HTML 元素。
- 排除不参与显示的 `symbol` 定义；实际页面存在 204 个。把 symbol 再加回候选列表，会让设置开关的样式计算从约 40–50 ms 回到约 130–140 ms。
- CSS 热替换对照隔离了该因素；最终又重新加载完整构建做整版复测。各实验记录在 `experiments/`，不混入最终统计。
- 插件页面 32 个 SVG 的遮罩、颜色、背景、尺寸及直接子节点 display 全部对照，差异为零，见 `icon-equivalence.json`。

### 2. 同一偏好被重复选择仍触发写入与订阅刷新

旧版 9 次选择已经选中的色温产生 36 条 body 属性变更记录。新版相同操作为 0；实际切换暖色再切回中性色，仅产生 2 条必要属性变更。相同窗口焦点状态也不会重复写属性。

插件列表中的静态摘要不再挂载主题变化订阅；完整偏好控件仍按需订阅并在卸载时清理。

### 3. 设置导航不必要的重建与暂存节点

- 仅图标子树变化、页面按钮/标签/语言不变时，保留原有分组节点。
- 缓存规范化搜索文本，相同过滤结果不重复写 DOM。
- 页面按钮被宿主替换后，立即恢复旧节点属性并从暂存 Map 移除，不再一直持有到关闭设置。
- 原生 DOM + MutationObserver 检查替换 40 次页面按钮、图标延迟插入、搜索、Enter 原点击处理器、语言变化与卸载；全部通过。重复相同查询写入次数为 0。

## 复测方法与范围

1. 用同一隔离 profile 运行真实 DSH，加载对应构建；关闭首次引导，保持窗口为 1280×720、相同语言/主题。
2. 开启 Chromium Performance 指标；每次执行“Settings 按钮 → Close”前后读取指标差值，运行 12 次；输入框填入 `Performance audit draft N` 同样运行 12 次并清空。
3. 插件页面重复设置开关 8 次；每组排除首个样本取中位数。CPU sampling 与 CSS 对照实验单独运行，不混入最终基准。
4. 在同一页面临时应用原始/优化 CSS，对照 SVG 的 maskImage、color、backgroundColor、width、height 和子元素 display；最终恢复正式构建。
5. 在独立 HTMLDocument 中调用 `scripts/check-settings-navigation.browser.mjs`，使用原生 MutationObserver 验证增量更新和清理，避免改动应用内容。

覆盖主页输入、设置、插件列表、偏好切换与生命周期。未覆盖长会话的真实模型流式输出、终端/网页重负载、数小时运行和其他操作系统；不能把这些采样当作所有工作负载的性能保证。
