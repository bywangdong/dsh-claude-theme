# 0.11.5 `f` 快捷键会话与项目搜索面板视觉验收记录

2026-11-15 · DeepSeek Harness `0.2.2-rc.3` · `dsh-shortcutter@0.1.40` · `dsh-theme-claude@0.11.5`

## 校准目标（对齐 Claude Desktop `Search sessions and projects`）

1. **悬浮命令面板壳层**：`600px` 宽度、`12px` 圆角、深色 `#303030` 面板底与 `1px #404040` 描边（浅色 `#FFFFFF` / `#E5E5E5`，暖纸 `#2B2A27` / `#FAF9F5`），遮罩去模糊降噪；同步调和 `.sc-root` 浮层色板（含右下角快捷模式提示胶囊）。
2. **52px 搜索顶栏**：前置 `16×16px` 线性放大镜（`x = 20px`）、`14px / 20px` 输入框（去除聚焦蓝色外框，赤陶色光标，占位文案本地化为 `搜索会话与项目` / `Search sessions and projects`）与右侧 `28×28px` 线性 `✕` 按钮；结果存在时隐藏顶部会话统计与底部快捷键栏，空结果时居中展示状态提示。
3. **32px 单行结果胶囊与相对时间**：每行前置 `16×16px` `</>` 代码会话图标（与顶栏放大镜同轴对齐），选中行采用 `#4F4F4F` / `#EAEAEA` `8px` 圆角胶囊并在右侧渲染 `14×14px` `↵` 回车箭头；未选中行基于 `ctx.sessions.list` 的 `updatedAt` 展示本地化相对时间分段（`今天` / `昨天` / `过去一周` / `过去一个月` / `过去一年`），按工作区名检索命中时内联附带项目名。
